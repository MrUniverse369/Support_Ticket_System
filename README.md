# Support Ticket System

A **full-stack web application** to manage support tickets, featuring ticket creation, status tracking, assignment, and a modern dashboard with visual stats. Built with **Node.js, Express, PostgreSQL, HTML, CSS, and JavaScript**, this project demonstrates full-stack development and SQL skills.  

---

## Features

- **Create Tickets** – Users can create new support tickets with title, description, and priority.
- **View Active Tickets** – See all active tickets in a clean, modern ticket card layout.
- **Complete Tickets** – Mark tickets as completed without removing them.
- **Last 3 Completed Tickets** – Only the most recent three completed tickets are visible for easy tracking.
- **Assign Tickets** – Placeholder buttons to assign tickets to users (expandable for multiple users).
- **Dashboard Stats** – Shows total tickets, open, in-progress, and completed counts.
- **Bar Chart** – Visualizes ticket status distribution dynamically using Chart.js.
- **Modern, Professional Design** – Clean interface, responsive layout, subtle shadows, and hover effects for ticket cards.

---

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL  
- **Charting:** Chart.js  
- **Deployment:** Render / Local Development
